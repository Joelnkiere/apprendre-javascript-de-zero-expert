# Apprendre JavaScript pour Débutants

## Formateur
Joel Nkiere – Développeur Fullstack

## Objectifs

Cette formation permet d'apprendre JavaScript depuis zéro.

À la fin de ce cours vous serez capable de :

- Comprendre la syntaxe JavaScript
- Créer des programmes simples
- Manipuler des variables
- Utiliser les conditions
- Utiliser les boucles
- Créer des fonctions
- Développer une logique de programmation solide

## Prérequis

Aucun prérequis en programmation.

## Logiciels

- Google Chrome
- Visual Studio Code
- Node.js (facultatif pour la première partie)
