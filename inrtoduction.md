# Qu'est-ce que JavaScript ?

JavaScript est un langage de programmation créé pour rendre les pages web interactives.

Grâce à JavaScript on peut :

- Réagir aux clics
- Créer des formulaires dynamiques
- Afficher des animations
- Communiquer avec un serveur

Exemple :

```javascript
alert("Bonjour !");
```

# Client vs Serveur

## Côté client

Exécuté dans le navigateur.

Exemple :

```javascript
document.body.style.background = "blue";
```

## Côté serveur

Exécuté sur un serveur Node.js.

Exemple :

```javascript
console.log("Serveur démarré");
```
